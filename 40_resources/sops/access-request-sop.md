# SOP: access requests and removals

1. Request names the person, the system, the access level and the end date.
2. Client systems: the client creates a named account; we never share logins
   ([[data-access-policy]]).
3. Internal systems: [[Clara-Benson]] sets up accounts for new hires ([[people-onboarding-routine]]).
4. Passwords live in the password manager, never in the brain or chat.
5. Removal at offboarding or role change, same day ([[client-offboarding-sop]]).
