# SOP: suspected data incident

1. Stop: revoke the access or pull the file. Don't delete evidence.
2. Tell [[Sam-Whitaker]] and [[Dana-Kettlewell]] within one hour.
3. Write what happened, when, which data, which client into a private note (not the brain).
4. Dana calls [[Pembury-Lane-Legal]] before telling the client; contracts may set notice deadlines
   ([[contract-playbook]]).
5. Afterwards: a retro and, if needed, an ADR ([[decisions-need-revisit-triggers]]).
