# Routine: month-end close

**Agent:** CFO (prep) · **When:** first three business days of the month · **Human:** [[Priya-Raman]]

1. Agent lists transactions without a receipt and drafts a request list per person.
2. Agent compares invoices sent ([[invoice-run-sop]]) with retainer contracts ([[service-catalog]]).
3. Agent flags unusual items (new vendors, duplicates) for Priya, especially AI tools without a
   DPA ([[ADR-013-vendor-dpa-before-any-ai-tool]]).
4. Priya closes the books and sends the package to [[Ashgrove-CPA-Group]].
5. Totals (not details) go to [[finance-kpis]].
