# Quarterly reviews start with the client's goals

Open the QBR with the goal the client set, then show only metrics that move it. Activity
metrics on page one lose the CFO in minute two.

**Evidence:** [[2026-09-03-ironfern-qbr-notes]]: open rates first, and the client's CFO asked what
that had to do with referrals.

**Applied:** [[ironfern-ops-retainer]], [[client-reporting-dashboard]], [[role-scorecards]].
