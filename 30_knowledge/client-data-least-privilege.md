# Client data: least privilege, ended at offboarding

Each person and tool gets the narrowest access a project needs, in the client's own system, and
loses it the day the project ends.

**Why:** fewer accounts, fewer ways to leak; and clients ask about it in security questionnaires
([[security-questionnaire-library]]).

**Applied:** [[data-access-policy]], [[access-request-sop]], [[client-offboarding-sop]],
[[ADR-007-client-data-stays-in-client-crm]].
