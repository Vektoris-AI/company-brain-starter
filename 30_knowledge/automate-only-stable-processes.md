# Automate only processes that have been stable for weeks

If a process still changes every week, an automation freezes yesterday's version. Run it by hand
(or with a checklist) until it holds for about four weeks.

**Evidence:** [[time-tracking-migration]] (fixed project codes first), [[cobaltline-crm-migration]]
(drop unused workflows), our agents ([[2026-08-05-ai-leadership-pilot-notes]]).

Applied in [[cto-automation-review-routine]]. Related: [[crm-hygiene-before-automation]].
