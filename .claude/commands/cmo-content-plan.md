# /cmo-content-plan

Run as agent `cmo` for `$ARGUMENTS` (default: next month). Routine page:
`20_areas/marketing/cmo-content-plan-routine.md`.

1. Read `positioning.md`, `brand-voice.md` and the current `editorial-calendar-*.md`.
2. Collect material: knowledge pages and retros added or updated since the last plan.
3. Propose one topic per posting slot, each tied to exactly one source page.
4. Check each topic: client named? approval on file? numbers sourced? consistent with the
   service catalog?
5. Draft 2 to 3 posts in the brand voice, each with author and posting day.
6. Write `00_inbox/<YYYY-MM-DD>-cmo-content-plan.md`.

**Always:** follow the brain's schema contract (`CLAUDE.md`). Output is a draft
(`type: inbox`, `status: draft`, honest `confidence`, `sources` linking the pages you used).
Sources you could not reach go under `## Not checked`. Never send, never move money, never sign,
never commit. Reply in chat with a summary that fits on one screen and the path of the draft.
