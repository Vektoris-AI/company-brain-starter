# ADR-012: One project management tool for everyone

## Context
Two project tools ran in parallel ([[2026-07-02-tool-audit-export]]); status lived in both.

## Options

| Option | Pros | Cons |
|---|---|---|
| A: One tool, migrate by end of August | One place for tasks | Migration effort |
| B: Keep both | No effort | Double entry, missed tasks |

## Decision
A. Decided by [[Marcus-Finch]] and [[Sam-Whitaker]] on 2026-07-08.

## Consequences
Tasks in the project tool, decisions and status in the brain ([[tool-stack]]).

## Revisit when
The tool can't handle sprint slots ([[capacity-board]]).
